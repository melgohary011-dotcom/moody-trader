# Moody Trader v0.4 — Render Ready + Mansa Real Analysis

النسخة تربط قائمة وأسعار EGX بـ Mansa API وتضيف:

- Historical OHLCV endpoint.
- RSI 14.
- MACD 12/26/9.
- SMA 20 / SMA 50 / EMA 20.
- ATR 14.
- دعم ومقاومة من آخر 20 جلسة.
- شارت تاريخي حقيقي عندما تسمح خطة Mansa.
- Cache لمدة 25 دقيقة لقائمة السوق لتقليل استهلاك الـ API.
- Daily snapshots محلية تلقائية كخطة بديلة لتجميع تاريخ حقيقي بمرور الأيام.

## ملاحظة مهمة عن خطة Mansa
وفق توثيق Mansa الحالي، endpoint التاريخي العميق `/history` متاح على Professional tier. مفتاح Standard يستمر في تشغيل الأسعار الحالية وقائمة EGX، لكن قد يعيد رفضًا لطلب التاريخ. Moody Trader لا يختلق RSI أو MACD في هذه الحالة؛ يعرضها فقط عندما توجد بيانات تاريخية كافية.

## التشغيل
1. فك الضغط.
2. افتح Terminal داخل المجلد.
3. `npm install`
4. `npm start`
5. افتح `http://localhost:3000`

ملف `.env` في النسخة الخاصة بك يحتوي مفتاح Mansa. لا ترفعه إلى GitHub ولا ترسله لأي شخص.

## النشر على Render

1. ارفع السورس إلى مستودع Git خاص بك، بدون ملف `.env`.
2. أنشئ Render Blueprint من المستودع؛ ملف `render.yaml` يضبط الخدمة تلقائيًا.
3. عندما يطلب Render قيمة `MANSA_API_KEY`، أضفها كمتغير سري.
4. اضغط Deploy وانتظر حتى تظهر حالة Live.

الخطة المجانية تتوقف بعد 15 دقيقة من عدم الاستخدام، وقد تستغرق قرابة دقيقة لتعمل عند أول فتح. كما أن ملفات الـsnapshot المحلية تُمسح عند إعادة التشغيل؛ الأسعار الحالية من Mansa تستمر في العمل، أما التخزين التاريخي الدائم فيحتاج قاعدة بيانات لاحقًا.
